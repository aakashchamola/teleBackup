# teleBackup: guide for family

The complete guide is **[USER_GUIDE.md](USER_GUIDE.md)**: install, the first setup step by step, daily use, every rule setting, how deleting works, finding your files in Telegram, and what to do when something is wrong.

Three things to know before anything else:
1. **Nothing is deleted from your phone** until you open a rule and choose "Delete from phone after N days", read the warning, and approve the first list of files. You can stop all deletes from Settings at any time.
2. **Never uninstall the app to update it.** Install the new file over the old one. Uninstalling erases the app's record of what is already backed up.
3. If something looks stuck, open **Home**: each warning has one button that fixes it. If that does not help, open **Settings > Diagnostics > Share** and send the text to the person who set this up. It has no passwords or tokens in it.
