# M0: Tools and hello-world

**Goal:** the owner's own computer can build the app, the owner's phone is connected in debug mode, and a blank teleBackup app runs on it and talks to its own Kotlin side once.

**Where:** the owner's own computer (not the shared work machine; the owner decided on 2026-11-01 not to install there). Linux steps below; on Windows use WSL 2 and see `docs/SETUP.md` for the USB note.

**Done when:** `flutter doctor` has no red marks for Android; `adb devices` lists the phone as `device`; the hello screen on the phone shows "Kotlin says: pong (Android NN, <model>)"; the code is pushed.

## Before you start
- [x] At least **15 GB free** disk (`df -h ~`). Flutter ~1.5 GB, Android SDK ~3-4 GB, Gradle caches 1-2 GB, TDLib later 1-3 GB.
- [x] Clone: `git clone https://github.com/aakashchamola/teleBackup.git` and `cd teleBackup`. Read `CLAUDE.md`.
- [x] Tell the owner before each big download (CLAUDE.md rule). This file *is* the list; one "go" for the whole list is enough.

## Tasks

### 1. JDK 17
- [x] `sudo apt update && sudo apt install -y openjdk-17-jdk`
- [x] `java -version` shows 17. If another Java is the default: `sudo update-alternatives --config java` (pick 17), or later point Flutter at it with `flutter config --jdk-dir /usr/lib/jvm/java-17-openjdk-amd64`.

### 2. Flutter (stable)
- [x] `sudo apt install -y git curl unzip xz-utils zip libglu1-mesa`
- [x] `git clone https://github.com/flutter/flutter.git -b stable ~/flutter`
- [x] Add to `~/.bashrc`: `export PATH="$HOME/flutter/bin:$PATH"`, then `source ~/.bashrc`
- [x] `flutter --version` and write the version into `docs/SETUP.md` ("Pinned Flutter: x.y.z").
- [x] `flutter config --no-analytics` and `dart --disable-analytics`
- [x] `flutter config --no-enable-web --no-enable-linux-desktop` (Android only keeps it lean)

### 3. Android SDK (command-line only, no Android Studio, no emulator)
- [x] Download "Command line tools only" for Linux from developer.android.com/studio (section "Command line tools only").
- [x] `mkdir -p ~/Android/Sdk/cmdline-tools && unzip commandlinetools-linux-*.zip -d ~/Android/Sdk/cmdline-tools && mv ~/Android/Sdk/cmdline-tools/cmdline-tools ~/Android/Sdk/cmdline-tools/latest`
- [x] Add to `~/.bashrc`:
  ```
  export ANDROID_HOME="$HOME/Android/Sdk"
  export PATH="$ANDROID_HOME/cmdline-tools/latest/bin:$ANDROID_HOME/platform-tools:$PATH"
  ```
  The SDK's `platform-tools` must come **before** `/usr/bin` so its `adb` is used (two different `adb` versions fight over the server).
- [x] `sdkmanager --list | grep -E "platforms;android-|build-tools;" | tail` to see the newest.
- [x] `sdkmanager "platform-tools" "platforms;android-<newest>" "build-tools;<newest>"` (use what `flutter doctor` asks for if it names a version).
- [x] `flutter config --android-sdk ~/Android/Sdk`
- [x] `flutter doctor --android-licenses` (accept all)
- [x] `flutter doctor -v`: Flutter and Android toolchain green. Chrome/Linux/Android Studio warnings are fine to ignore.

### 4. Phone in debug mode (USB cable, the owner's choice)
- [ ] Phone: Settings > About phone > tap **Build number** 7 times.
- [ ] Settings > System > Developer options > **USB debugging** on. (Xiaomi: also **USB debugging (Security settings)** and **Install via USB**.)
- [ ] Plug in with a data cable. If asked, pick **File transfer**.
- [ ] Accept "Allow USB debugging?" on the phone (tick "Always allow from this computer").
- [ ] `adb devices` shows `<serial>  device`.
  - `no permissions` -> `sudo apt install -y android-sdk-platform-tools-common` (udev rules), `sudo usermod -aG plugdev $USER`, log out and in, replug.
  - `unauthorized` -> revoke USB debugging authorisations on the phone, replug, accept again.
  - nothing listed -> another cable (many are charge-only), or another USB port.
- [ ] Note the phone: `adb shell getprop ro.product.model`, `adb shell getprop ro.build.version.release`, `adb shell getprop ro.build.version.sdk`. Write them in `docs/SETUP.md` ("Owner's phone").

### 5. Create the Flutter app
From the repo root:
- [x] `flutter create --org com.aakashchamola --project-name telebackup --platforms android --android-language kotlin --description "Backs up photos and videos to your own Telegram" app`
- [ ] `cd app && flutter run -d <serial>`: the default counter app runs on the phone. Hot reload (`r`) works. Quit with `q`.
- [x] `app/android/app/build.gradle.kts`: `minSdk = 30`. Keep `compileSdk`/`targetSdk` = `flutter.compileSdkVersion`/`flutter.targetSdkVersion`. Java/Kotlin target 17.
- [x] `AndroidManifest.xml`: `android:label="teleBackup"`, `android:allowBackup="false"`, `android:dataExtractionRules="@xml/data_extraction_rules"` (exclude everything; add `res/xml/data_extraction_rules.xml`), `android:fullBackupContent="false"`.
- [x] Merge ignores: keep `app/.gitignore` from Flutter; check the root `.gitignore` still covers `local.properties`, `key.properties`, `*.jks`. Run `git status` and confirm `app/android/local.properties` is **not** listed.

## Things that can go wrong
| Symptom | Fix |
|---|---|
| Gradle: "Unsupported class file major version" | Gradle is running on the wrong Java. `flutter config --jdk-dir <jdk17>`; `flutter doctor -v` shows which Java it uses. |
| First `flutter run` hangs at "Running Gradle task" for 10+ min | First build downloads Gradle + deps (1-2 GB). Wait; check network. |
| `INSTALL_FAILED_USER_RESTRICTED` (Xiaomi) | Developer options > Install via USB on (needs a Mi account sign-in). |
| `adb server version doesn't match` | Two `adb`s. `which -a adb`; make the SDK one first on `PATH`; `adb kill-server`. |
